# Portfólio · Segurança da Informação

## Como abrir
1. No VS Code: Arquivo > Abrir Pasta e escolha `portfolio-beatriz`.
2. Instale a extensão **Live Server** e clique em "Go Live" (canto inferior direito). Ou abra o `index.html` direto no navegador.

## Estrutura
- `index.html`: conteúdo e textos das seções
- `css/style.css`: cores (variáveis no topo, em `:root`), layout e animações
- `js/main.js`: filtro de projetos, botão de tema e efeito glitch
- `assets/mascote.png`: seu personagem

## O que falta preencher
- E-mail, LinkedIn e GitHub (seção `#contato`)
- Links "Ver no GitHub" dos projetos (procure `href="#"`)

## Publicar de graça
Suba a pasta num repositório no GitHub e ative o GitHub Pages em Settings > Pages.
